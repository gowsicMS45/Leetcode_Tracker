# LeetCode Tracker

Collection of LeetCode problem solutions written in Python, Java, and C++.

## Overview

This repository tracks my data structures and algorithms practice. Each folder contains a solution for a specific LeetCode problem, usually named with the problem number and title.

## Languages

- Python
- Java
- C++

## Topics Covered

- Arrays and strings
- Linked lists
- Binary trees
- Binary search
- Dynamic programming
- Hash maps and sets
- Sliding window
- Recursion and backtracking

## Structure

```text
problem-number-problem-title/
  solution files
  README/problem statement when available
```

## Goal

The purpose of this repository is to document consistent problem-solving practice and improve algorithmic thinking.
